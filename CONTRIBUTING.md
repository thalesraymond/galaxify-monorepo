# Contributing to Galaxify

Thanks for your interest in helping out! This is a study project, so the guidelines below are intentionally lightweight.

## How to contribute

1. **Open an issue first** (or comment on an existing one) so we know what you're working on and avoid duplicate effort.
2. **Fork the repository** and create a branch for your change.
3. **Make your changes** and keep them focused on the issue.
4. **Run the checks** before opening a pull request:

   ```sh
   make build
   make test
   make vet
   ```

5. **Open a pull request** and fill out the PR template.

## What we're looking for

- Bug fixes
- Small, focused features
- Documentation improvements
- Tests for existing code

## What we're not looking for

- Large refactors without prior discussion
- New services or major architecture changes without an issue

## Code style

- Follow the existing Go conventions in the repo.
- Keep functions small and names descriptive.
- Add tests when it makes sense.

## Questions?

Feel free to open an issue with your question.
